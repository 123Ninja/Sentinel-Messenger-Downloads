# Sentinel Messenger Downloads

Public application downloads for [Sentinel Messenger](https://sentinel-messenger.vercel.app/).

[Open the download page](https://sentinel-messenger.vercel.app/download/).

This repository contains release artifacts only. The application source repository remains private.

The Android ARM64 APK is a preview using a development signing certificate. Physical-device behavior has not yet been verified. The iOS configuration is a removable Home Screen web app shortcut, not a native iOS application.
